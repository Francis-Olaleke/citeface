# Citeface Publishing — User Stories

**Status:** Draft for Build 0
**Priority labels:** P0 = required for initial publishing MVP; P1 = important follow-up; P2 = later enhancement.

## A. Create and publish

| ID | Priority | User story |
|---|---|---|
| PUB-001 | P0 | As a researcher, I want to choose a publishing format so that I can communicate my work in the most suitable way. |
| PUB-002 | P0 | As a researcher, I want to publish a written research story so that I can explain my research to a wider audience. |
| PUB-003 | P0 | As a researcher, I want to publish a short video between 90 seconds and five minutes so that I can demonstrate or explain my work. |
| PUB-004 | P0 | As a researcher, I want to publish research photographs with explanatory text so that readers can see relevant work or observations. |
| PUB-005 | P0 | As a researcher, I want to publish a paper announcement so that I can introduce a publication or research document. |
| PUB-006 | P0 | As a researcher, I want to publish a methods-focused post so that I can explain a technique, protocol or research workflow. |
| PUB-007 | P0 | As an author, I want to choose the audience for each post so that I control who can access it. |
| PUB-008 | P0 | As an author, I want to include an optional DOI or source link so that readers can locate the original research when one exists. |
| PUB-009 | P0 | As an author, I want to see whether my media upload succeeded so that I do not mistake an incomplete upload for a published post. |
| PUB-010 | P0 | As an author, I want clear feedback when publishing fails so that I can correct the problem and retry. |

## B. Research context and trust

| ID | Priority | User story |
|---|---|---|
| PUB-011 | P0 | As a reader, I want to see the author's identity and the post's content type so that I understand who is communicating and what kind of content I am viewing. |
| PUB-012 | P0 | As a reader, I want to see source and publication-status information when supplied so that I can interpret the research context. |
| PUB-013 | P0 | As a reader, I want to open the original source link when one is provided so that I can inspect the underlying work. |
| PUB-014 | P0 | As a platform, I want to distinguish a research story from a peer-reviewed publication so that the interface does not imply unsupported scientific validation. |
| PUB-015 | P0 | As an author, I want to confirm that I have the right to share uploaded media so that the platform can discourage unauthorized sharing. |

## C. Post management and safety

| ID | Priority | User story |
|---|---|---|
| PUB-016 | P0 | As an author, I want to edit or remove a published post subject to platform rules so that I can maintain control over my contributions. |
| PUB-017 | P0 | As a reader, I want to report a post so that potentially harmful, misleading or rights-infringing content can be reviewed. |
| PUB-018 | P1 | As an author, I want to add a correction to a post so that readers can see when information has changed. |
| PUB-019 | P1 | As a reader, I want to see a correction or retraction notice when relevant so that I am not left with outdated research context. |

## D. Explicitly excluded from the first release

| ID | Priority | User story |
|---|---|---|
| PUB-020 | Out of scope | As an author, I want to save an unfinished post as a draft. |
| PUB-021 | Out of scope | As an author, I want to schedule a post for a future time. |
| PUB-022 | Out of scope | As an author, I want advanced in-app video editing tools. |

The first MVP decision is **no saved drafts**. Temporary technical upload states are not drafts and must not be represented as such.
